# NovelFound · PC 端小说搜索与阅读器

一个用 **Python + PyQt5** 写的桌面小说搜索/阅读器（"笔趣阁风格"）：
输入书名 → 多书源并发搜索 → 卡片式结果 → 简介 + 完整目录 → **应用内直接阅读**，
全程过滤广告、弹窗与无关链接，只保留纯净正文。

支持 Windows / macOS / Linux，可打包成免安装单文件可执行程序。

---

## 一、功能总览

| 模块 | 说明 |
| --- | --- |
| 搜索 | **`Ctrl+K` 唤起搜索浮层**（或点右上角 🔍），输入 300ms 后自动搜索；**同时并发查询所有已启用书源**，某个源失败不影响其它源；结果行支持 `↑/↓` 选择、`Enter` 打开、`Esc` 关闭 |
| 结果展示 | 结果行：封面（自动下载并缓存）、书名、作者、状态/分类、最新章节、书源标签 |
| 书籍详情 | 点击结果或书架封面进入：大封面、作者/分类/章节数/已缓存数、简介（默认 3 行，可展开）、**只保留一个主按钮**（开始/继续阅读）；目录改为**左侧抽屉**（带章节筛选、当前章高亮） |
| 书架首页 | **启动首屏**：只放一屏书架封面网格（封面 + 书名 + **百分比文字**、封面右下角**进度角标**，未读显示「未读」，不放进度条）；鼠标悬停封面会浮出「查看详情」；书架为空时显示引导语 + 搜索按钮 |
| **本地导入** | 支持导入本地 **TXT / EPUB**：点书架首页「＋ 导入 TXT / EPUB」或**把文件拖进窗口**；自动识别编码（UTF-8/GBK/UTF-16）、自动切章（`第X章/回/卷`、`楔子/番外`…认不出就按长度分块）、EPUB 读 OPF spine 与封面；导入后**进书架就能直接读**，也能被搜索到 |
| **书架管理** | 书架封面右键可「移出书架 / 打开文件位置 / 删除本地书」；书架页右上角「本地书管理」列出入库的书（格式/章数/占用空间/导入时间），支持删除、重新导入、打开位置，并可「清理失效记录」——删除本地书会级联清掉文件、缓存、浏览历史与阅读进度（确认框里显示明细） |
| **浏览历史** | 右上角 🕘 按钮（`Ctrl+H`）：**一本书只留一条**（同一本书反复打开或读很多章都不会重复），在**离开阅读器或关闭应用**时写入，记录最近读到哪一章（时间 + 书名 + 章节 + 书源），点一条即可回到那本书、那一章；最多保留 30 条，可一键清空 |
| 内置阅读器 | 章节正文在应用内加载，**不跳转原网页**；正文居中限宽（默认 820px），**支持单页 / 左右双页分栏**，字号、行距、段距、**首行缩进**、字体、背景色可调；上下控制条**鼠标靠近边缘才出现**（200ms 淡入淡出），底部常驻 2px 进度线；滚动 / 整页翻页两种模式 |
| **阅读设置浮层（Aa）** | 阅读器右上角 `Aa`：字号 ± / 字体 / 行距 / 段距 / 首行缩进 / 正文宽度 / 背景主题 / 翻页方式 / 单双页 / 全屏，**改完即时生效**，不用点确定；顶部工具栏因此只剩「返回 · 书名 · 目录 · Aa · 全屏」 |
| 广告屏蔽 | DOM 层删除脚本/样式/iframe/广告位/隐藏节点，文本层再按正则过滤"最新网址、请记住本站、推广、外链、求票"等广告行；可开启**严格模式**进一步剔除纯英文推广行与正文内链接 |
| 书架 / 历史 | 一键加入书架；未加入书架的书也会记录阅读历史与进度（历史只用于记进度，首页只展示书架里的书） |
| 本地缓存 | 章节正文、目录、封面均落地 SQLite，支持离线重读，减少对站点的请求 |
| **书源导入 / 订阅** | 支持导入本项目规则 JSON 与**开源「阅读」(Legado) 书源 JSON**（自动转换，含 JS/XPath 规则的源会被安全跳过）；可维护订阅地址，按设定间隔自动更新 |
| **探测新书源** | 给一个站点域名，自动试出可用的搜索入口与解析模板（搜索 → 目录 → 正文三关验证），预览确认后一键保存为书源 |
| **网络找书源** | 连站点都不知道时：用搜索引擎按书名找候选站，再自动验证「能搜到这本书 + 能解析目录和正文」，只推荐真正可用的；搜索 0 结果时在浮层里直接给入口 |
| **书源评分 / 自动禁用** | 记录每个书源的成功率、平均耗时与连续失败次数；连续失败达到阈值自动禁用并提示，避免反复白等超时 |
| 容错 | 超时/重试/编码自动识别/SSL 过期降级；站点改版时给出中文提示并建议切换书源；书源可用性一键检测 |
| 可扩展 | 书源采用"规则驱动"，新增同模板站点只需加一条 JSON 配置（界面内即可添加） |

## 二、安装与运行

### 1. 环境要求

- Python 3.8 及以上（开发环境实测 3.13）
- 能访问公网（搜索与阅读需要联网；已缓存的章节可离线阅读）

### 2. 安装依赖

```bash
# 建议先建虚拟环境
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

依赖清单（详见 `requirements.txt`）：

| 库 | 用途 |
| --- | --- |
| `PyQt5` / `PyQt5-Qt5` / `PyQt5-sip` | 桌面 GUI |
| `requests` | HTTP 会话、超时与重试 |
| `beautifulsoup4` | HTML 解析 |
| `lxml` | 解析后端（更快更容错；缺失时自动回退 `html.parser`） |
| `pyinstaller`（可选） | 打包成 exe / app |

### 3. 运行

```bash
python main.py
```

Windows 用户也可以直接双击 `run.bat`：它会自动完成"建虚拟环境 → 装依赖 → 启动"，
**若项目目录下已经存在可用的 `.venv`（例如本机开发环境），则跳过安装直接启动**，
不需要再手动执行 `pip install`。

> `run.bat` 使用 ASCII 编码 + CRLF 换行编写，确保在任意 Windows 代码页下都能被
> `cmd.exe` 正确解析（用 UTF-8/LF 保存的批处理会解析失败）。

### 4. 打包为可执行程序

```bash
pip install pyinstaller
pyinstaller --noconfirm --distpath dist --workpath build/pyi build/novelfound.spec
```

**默认产出 onedir 目录模式（推荐）**：

```
dist/NovelFound/
├── NovelFound.exe      ← 双击运行
└── ...（Qt 与依赖 DLL，约 100 MB）
```

分发时把整个 `NovelFound` 文件夹一起拷贝即可，目标机器**无需安装 Python**。
该模式启动快、不写系统临时目录，也更不容易被安全软件误报。

**单文件模式（可选）**：

```bash
# Windows
set NOVELFOUND_ONEFILE=1 && pyinstaller --noconfirm --distpath dist --workpath build/pyi build/novelfound.spec
# macOS / Linux
NOVELFOUND_ONEFILE=1 pyinstaller --noconfirm --distpath dist --workpath build/pyi build/novelfound.spec
```

产出单个 `dist/NovelFound.exe`（约 45 MB）。首次启动会把自己解包到系统临时目录，
因此要求当前用户对临时目录有写权限；若受限（例如在某些受限沙箱/企业策略下），
会报 `Could not create temporary directory`，此时请改用默认的 onedir 模式。

**打包后自检**（不需要打开界面，验证 exe 里的搜索/解析链路是否完好）：

```bash
dist\NovelFound\NovelFound.exe --selftest 斗罗大陆
```

它会跑一遍 搜索 → 目录 → 正文，退出码 0 表示通过，
并把详细报告写到数据目录下的 `selftest.txt`（无控制台窗口时也能查看）。

- Windows 上若首次运行被 SmartScreen 拦截，点"更多信息 → 仍要运行"即可（未签名程序）。
- macOS 产物为 `dist/NovelFound.app`；首次打开若提示"未验证开发者"，
  可在"系统设置 → 隐私与安全性"里选择"仍要打开"，或执行
  `xattr -dr com.apple.quarantine dist/NovelFound.app`。
- spec 里已排除 WebEngine 等无用模块以压缩体积。

### 5. 数据目录

配置、书架、缓存统一放在用户数据目录，可随时删除或备份：

| 系统 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\NovelFound\` |
| macOS | `~/Library/Application Support/NovelFound/` |
| Linux | `~/.local/share/NovelFound/` |

包含 `config.json`（设置）、`library.json`（书架与进度）、`cache/cache.db`（缓存）。
设置环境变量 `NOVELFOUND_HOME` 可指定其它目录（绿色版/便携模式）。

## 三、使用说明

### 搜索与阅读流程

1. 按 `Ctrl+K`（或点右上角 🔍）打开搜索浮层，输入书名（例如"斗罗大陆"）——输入停顿 300ms 后自动搜索；
2. 结果行出现后，用 `↑/↓` 选中、`Enter` 打开（也可以直接点）；
3. 详情页可以看到封面、简介和元信息，点「目录」从左侧滑出完整目录（支持关键词筛选、点击任意章节）；
4. 阅读器里鼠标移到窗口顶部/底部，会浮出控制条（字号、背景、**单页/左右双页**、翻页方式、上一章/下一章）；左上角「‹ 返回」回到详情；底部控制条上的「目录」按钮（或 `Ctrl+B`）随时叫出目录抽屉；
   - 想双栏读：把排版切成「左右双页」即可（会自动切到翻页模式），翻页一次走两页；
5. 详情页「☆ 加入书架」后，回到**书架首页**就能看到封面与阅读百分比；点封面进详情，主按钮已变成「继续阅读」，直接接着上次那一章读。

### 阅读器快捷键

| 快捷键 | 作用 |
| --- | --- |
| `PageDown` / `空格` | 下一页（翻页模式下到底自动进入下一章） |
| `PageUp` | 上一页 |
| `←` / `→` | 上一章 / 下一章 |
| `Ctrl` + `=` / `Ctrl` + `-` | 增大 / 减小字号 |
| `Home` / `End` | 跳到本章开头 / 结尾 |
| `F5` | 重新抓取本章（忽略缓存） |
| `F11` | 沉浸式全屏 |
| `Esc` | 退出全屏 / 关闭浮层 |

### 主窗口快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + `K` / `Ctrl` + `F` | 打开搜索浮层（输入框自动聚焦） |
| `Ctrl` + `H` | 打开浏览历史（点条目回到当时那本书 / 那一章） |
| `Ctrl` + `B` | 打开 / 关闭目录抽屉 |
| `Esc` | 关闭搜索浮层 / 浏览历史 / 目录抽屉 |

### 设置项

- **阅读设置（阅读器里点右上角 `Aa`）**：字号、字体、行距、段间距、**首行缩进（0–4 字符，默认 2）**、**正文宽度（600–1200px，默认 820）**、**排版（单页 / 左右双页）**、背景主题（暖白 / 护眼 / 羊皮纸 / 夜间 / 深灰，默认暖白 `#F7F3E9`）、翻页方式、沉浸式全屏 —— **改完即时生效**。
- **设置对话框（右上角 ⚙）**：只放全局项，避免和 `Aa` 浮层出现"两处真相"。
  - **网络与缓存**：请求超时、失败重试次数、每源返回条数、**同站请求间隔**（默认 0.8 秒，带随机抖动，调大可降低被限流概率）、**封面并发数**（默认 2，封面只下可见卡片）、缓存开关与有效期、一键清空缓存。
  - **书源**：勾选启用、检测可用性、**导入书源 / 订阅**、添加/删除自定义书源、重置评分；每条书源后面会显示成功率、平均耗时、最近可用时间与连续失败次数。
  - **外观与其它**：严格广告过滤、是否自动加载封面。

> 关于「经常被拒绝访问」：程序会按站点排队限速（同站两次请求至少间隔设定秒数）、
> 请求头尽量贴近真实浏览器（含 `Sec-Fetch-*`、`sec-ch-ua`），并且**封面只在卡片滚到
> 可见区域时才下载、且并发受限**——避免一次搜索把同一个站瞬间打几十次。
> 若某站仍返回 403/429，多半是它的人机验证或 IP 限流，建议换源或稍后再试。

| `Ctrl+←` / `Ctrl+→` | 上一章 / 下一章 |

### 导入本地小说（TXT / EPUB）

1. 在**书架首页**点「＋ 导入 TXT / EPUB」（书架为空时按钮在引导语下方），或者
   **直接把文件拖进窗口**（支持多选与多文件拖入）；
2. 程序会把文件复制到数据目录 `local_books/`（原文件之后移走也不影响阅读），
   并解析出书名、作者与章节表；导入的书会**自动加入书架**，点封面即可阅读；
3. **编码自动识别**（优先按文件自己声明的编码，其次 UTF-8 / GB18030 / Big5，
   用增量解码判定，不会把 UTF-8 误判成 GBK）；章节按 `第X章`、`第X回`、
   `楔子 / 序章 / 番外 / Chapter N` 切分，认不出时按长度分块——**保证导进来就能读**；
4. **分卷（部/卷）折叠**：TXT 的 `第X部/卷`、EPUB 的 NCX 层级都会变成目录里的分组，
   **默认收起，当前章所在的那一卷自动展开**，可一键全展开/收起；
5. EPUB 按 OPF 的 spine 顺序取章节、用 NCX/nav 的**权威标题与分卷**，自动抓封面；
   **正文里的插图会显示出来**（按正文宽度等比缩放、居中）；
6. **本书插图**：目录抽屉里点「本书插图（N）」可浏览书里**所有**图片——
   包括那些在包里、但正文没有引用的插图（很多自制 EPUB 就是这样），可另存到本地；
7. 本地书同样支持目录抽屉、阅读器全部功能（分页/主题/进度记忆）、书架与「继续阅读」，
   也**能在搜索浮层里搜到**（书源列表里叫「本地导入」，可单独禁用）。

> 本地书源不联网，因此不参与「书源健康度自动禁用」；文件删了会在阅读时提示重新导入。

### 导入更多书源（解决"只有内置几个源"）

「设置 → 书源 → 导入书源 / 订阅…」支持三种来源：

1. **本项目规则 JSON**：单个规则对象或规则数组（字段见下一节）；
2. **开源「阅读」(Legado) 书源 JSON**：社区里最大的公开书源生态，导入时自动转换；
3. **订阅地址**：填写任意返回书源 JSON 的链接，可设置"启动时自动更新"与更新间隔（默认 7 天）。

可以直接用项目自带的示例文件试一遍：
[`tests/fixtures/legado_sample.json`](tests/fixtures/legado_sample.json) —— 里面有 2 个可用的
Legado 书源和 1 个含 JS 规则的书源（导入时会显示"不可用：使用了 JS/XPath/JSON 规则"）。

**安全边界**：程序只接受 URL 模板 + CSS 选择器这类**数据**，绝不执行书源里的 JS 脚本；
含 `<js>`、`@XPath:`、`$`(JSONPath) 规则的源会被标记为不可用且无法勾选。

**自动禁用**：某书源连续失败达到阈值（默认 5 次，可在设置里调）会被自动取消勾选并提示，
避免每次搜索都白等一遍超时；在「书源」页点「重置评分」即可解锁重试。

### 探测新书源（把没写规则的站点加进来）

「设置 → 书源 → 探测新书源…」：**填一个小说站首页地址**，程序自动完成四关验证——

```
① 连通性    首页能否打开、是否被反爬拦截
② 搜索入口  把常见搜索写法逐个试一遍（?searchkey= / ?keyword= / /s?q= / /search/?keyword= …），
            拿到结果页后用几套模板的选择器比对，看能不能抠出书名+链接
③ 目录解析  挑一条结果进详情页，要求解析出 ≥3 章
④ 正文提取  打开第一章，要求正文 ≥300 字且不是导航页
```

四关全过就会展示预览（书名、作者、前三章、正文开头），确认后点「保存为书源」即写入配置并启用。
实测例子：探测 `https://www.hetushu.com` 会自动试出 `/search/?keyword={q}` + 和图书模板
（337 章 / 正文 2455 字）；探测 `https://www.mayiwsk.com` 会试出
`/modules/article/search.php?searchkey={q}` + 经典笔趣阁模板（719 章）。

- 只探到一半（比如搜索能用、目录没识别）时，会把**已探通的部分规则**填进 JSON 编辑器，
  补上目录/正文选择器即可保存；
- 探不出来会明确告诉用户卡在哪一关（域名不通 / 需要人机验证 / JS 渲染 / 模板未匹配）；
- 程序只读公开页面，**不执行站点脚本、不处理登录与人机验证**；
- 探测出来的规则与内置书源同构，站点改版后重探一次即可覆盖同名书源。

### 网络找书源（连站点都不知道时）

搜索没有任何结果时，顶部提示条会出现「网络找书源」按钮（也可以在
「设置 → 书源 → 网络找书源…」打开）：

1. 程序用搜索引擎按 **`书名 笔趣阁` / `书名 免费小说` / `书名 小说 在线阅读`**
   三个搜索词查找，合并去重后得到候选站点（自动过滤起点/云起/百科/TapTap 等
   官方、付费、游戏站）；
2. 对排名靠前的候选站（默认 5 个，可调）自动执行上一节的四关探测；
3. 额外校验**搜索结果必须与书名相关**——有些站的"搜索"其实返回固定列表，
   这类会被明确拒绝，避免存下"搜什么都返回同一批书"的假书源；
4. 通过验证的站点列在对话框里（含模板、目录章数、正文字数、前三章预览），
   勾选后保存启用，主界面会用同一个关键词自动重搜一次。

实测（本机网络，探测 4 个候选站）：

| 书名 | 结果 |
| --- | --- |
| 剑来 | ✓ 发现 `www.piquge.com`（`/search/?searchkey={q}` + 经典笔趣阁模板，112 章） |
| 大奉打更人 / 宿命之环 / 凡人修仙传 | 候选站分别因服务器 5xx、反爬、JS 渲染、搜索接口失效而未通过（对话框会逐条说明原因） |

**说明**：本机环境下只有 Bing 能稳定返回可解析的结果页（百度/360/搜狗/DDG 均被反爬或需要 JS），
所以引擎清单里默认只有 Bing；命中率取决于目标站点当时是否可访问，**它是一条兜底路径，不是保证**。
所有验证失败都会给出具体卡在哪一关，方便判断是"站挂了"还是"换个站试试"。

### 出问题时的日志

程序遇到内部错误时，会把完整 traceback 写入数据目录下的 **`crash.log`**
（Windows：`%APPDATA%\NovelFound\crash.log`），并尽量在界面上提示，而不是直接退出。
如果某个操作让你觉得"点了没反应"或程序异常关闭，先看这个文件。

## 四、书源说明

### 内置书源

| 书源 | 站点 | 默认 | 备注 |
| --- | --- | --- | --- |
| 和图书 | hetushu.com | ✅ | 结构稳定、正文干净，推荐首选 |
| 蚂蚁文学 | mayiwsk.com | ✅ | 经典笔趣阁模板 |
| 笔趣阁5200 | biquge5200.cc | ✅ | 老牌站点，GBK 编码，网络波动较大 |
| 笔趣阁365 | biquge365.net | ⬜ | 搜索有 15 秒频率限制，默认关闭 |

> 这类站点变动频繁，某个源失效属正常现象：搜索会继续使用其它可用书源，
> 也可以在「设置 → 书源 → 检测可用性」里看哪个源还活着。

### 添加自定义书源

在「设置 → 书源 → 添加 / 修改自定义书源」里粘贴一段 JSON 规则即可，字段说明：

```jsonc
{
  "key": "my_source",                       // 唯一标识
  "name": "我的书源",                        // 显示名
  "base_url": "https://example.com",        // 站点根地址
  "search_url": "/search.php?keyword={q}",  // {q} 会被替换为关键词
  "search_method": "GET",                   // 或 POST
  "search_data": { "s": "{q}" },            // POST 时的表单字段
  "encoding": "",                           // 站点编码，留空自动识别（老站可写 gb18030）
  "search_items": ["table.grid tr"],        // 搜索结果条目选择器
  "book_title": ["td:nth-of-type(1) a"],
  "book_link":  ["td:nth-of-type(1) a"],
  "book_author":["td:nth-of-type(3)"],
  "catalog_groups": ["#list dl"],           // 目录容器
  "catalog_items": ["dd a"],                // 目录项
  "content": ["#content"],                  // 正文容器
  "chapter_title": ["div.bookname h1"],
  "label_fields": { "category": ["类型"], "status": ["状态"] }
}
```

要点：

- 选择器是 **CSS 选择器**，写成数组按顺序尝试，第一个命中即用；
- 站点用 `类型：玄幻小说` 这类带标签文本时，用 `label_fields` 精确取值；
- 目录里若同时有"最新章节"预览块与"正文"块，解析器会按 `<dt>` 分段自动跳过预览块，
  并在检测到整体倒序时自动翻转，保证从第一章开始读；
- 规则表在 `novelfound/sources/builtin.py`，改内置书源或加新模板同理。

## 五、容错与广告屏蔽设计

### 抓取容错

- **网络层**：统一超时（默认 12 秒，可调）、指数退避重试、连接池复用；
  403/429 判定为反爬并给出"可能需要人机验证"的提示；
  SSL 证书过期时自动降级重试一次（会在日志中标记）。
- **编码**：按 响应头 charset → HTML meta → 启发式探测 → utf-8/gb18030 兜底
  逐一评分选最优，避免乱码。
- **结构变化**：选择器全部失效时会启用启发式兜底（按链接形态推断搜索结果、
  按全页最大文本块推断正文）；仍失败则抛出带中文说明的 `ParseError`，
  界面提示"站点结构可能已变化，请切换书源"，而不是展示空白或乱码。
- **多源冗余**：搜索逐源回报，单源异常只影响该源，其余结果照常展示。
- **书源自检**：设置里可一键检测所有书源连通性。

### 广告屏蔽

1. **DOM 层**：删除 `script/style/noscript/iframe/ins/object/embed`、广告位容器
   （`id="adt1"`、`class="ads"`、`#center_tip` 等，按词边界匹配，避免误删 `content_read` 这类名字）、
   隐藏元素与防盗版标记（`acronym/samp`）；
2. **容器定位**：按优先级挑选正文容器（而不是"文本最多"的节点），避免把导航、
   推荐位一起算进正文；
3. **文本层**：按正则过滤广告行——"最新网址 / 请记住本站 / 收藏本站 / 一秒记住 /
   笔趣阁 / 无弹窗 / 求收藏 / 求月票 / 点击下一页 / http(s) 外链 / 纯广告词"等，
   同时去重连续重复行、清理零宽字符；
4. **严格模式**（可选）：额外丢弃整行纯 ASCII 的推广行、含 emoji 的推广行，
   并把正文里的超链接整段移除；
5. **渲染层**：阅读器只渲染纯文本段落，不执行原站任何脚本、不加载原站图片/广告。

## 七、常见问题

> 开发过程中实际踩过的坑（环境、抓取解析、界面、打包，含原因与解法）整理在
> [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md)，排查问题时可先看这份。

**搜索没有结果？**
1. 换更短的关键词（如只输入书名前两个字）；2. 在「设置 → 书源」里启用更多书源并检测可用性；
3. 确认网络能访问对应站点（部分站点在特定网络下不可达）。

**提示"站点结构可能已变化"？**
说明该书源模板改版了。切换到其它书源即可；若想修复，打开对应网页查看新的
HTML 结构，按第四节的方法更新 `builtin.py` 里的选择器，或添加自定义书源。

**提示"站点拒绝了本次访问"？**
站点有人机验证或限流，稍后再试或换书源；也可在设置里调大超时与重试次数。

**正文是空的 / 抓到的是导航页？**
程序会识别并报错，而不会把导航当正文显示。点 `F5` 忽略缓存重抓，或换书源。

**想离线阅读？**
读过的章节会自动缓存（默认保留 30 天），再次打开同一章会直接读本地缓存，
状态栏会显示"来自缓存"。
