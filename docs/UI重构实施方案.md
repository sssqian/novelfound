# UI 重构实施方案（现代沉浸式阅读器）

> 依据：`docs/UI设计方案：现代沉浸式小说阅读器.md`
> 已确定的四个方向：
> 
> 1. 搜索结果 → **彻底改成 Ctrl+K 浮层**
> 2. 打开软件的第一屏 → **书架首页**
> 3. 配色 → **严格照方案 #F7F3E9 暖白**
> 4. 左侧栏 → **P1 阶段改为抽屉**
> 5. 强调色 → 暂不决定，先留 token 位置（只改一个变量的事）
> 
> 本文只描述**怎么改**，不含代码改动。执行时按 P0 → P1 → P2 分批，每批结束都要
> 通过「66 项单元测试 + 更新后的界面自检」。

## 1. 目标信息架构

一个窗口，四个"模式"（用 `QStackedWidget` 切换页面，浮层叠在上面）：

```
┌─ 应用窗口 ───────────────────────────────────────────┐
│  [浮层] 搜索面板（Ctrl+K）  目录抽屉  设置浮层        │
│                                                      │
│  ① 书架首页  ──点击书籍──▶  ③ 书籍详情               │
│       ▲                        │                     │
│       │                        │ 点「继续阅读」       │
│       └──返回──────────────────┴──▶ ④ 阅读器         │
│  ② 搜索面板（任意页面可唤起）──选中结果──▶ ③          │
└──────────────────────────────────────────────────────┘
```

### ① 书架首页（启动首屏）

> **落地时按反馈调整**：首页只保留「我的书架」网格，
> 原方案里的「继续阅读」大卡与「最近阅读」横排已去掉——
> 想接着上次读，点封面进详情页，主按钮本身就是「继续阅读」。

```
应用名                                    🔍   ⚙
──────────────────────────────────────────────
  我的书架（4）
  [封面]  [封面]  [封面]  [封面]     ← 列数随窗口宽度自适应
  书名     书名    书名    书名
   42%     未读    67%     5%       ← 只显示百分比文字，不放进度条
```

- 无大搜索框：搜索入口只有右上角图标 + `Ctrl+K`。
- 书架网格卡片 = **封面 + 书名 + 百分比文字**；按反馈**不放进度条**，
  未读过的书显示"未读"（不显示 `0%`）。
- 首页**只展示已加入书架的书**；阅读历史（`library.history()`）仍会记录进度，
  只是不再单独形成一个栏目。
- 书架为空时给引导语 + 一个「搜索小说」按钮（唤起搜索面板）。
- 封面网格懒加载（沿用现有封面节流：只下可见项、并发上限）。

### ② 搜索面板（浮层，替代常驻左侧结果栏）

- `Ctrl+K` / `Ctrl+F` / 点右上角 🔍 唤起；`Esc` 关闭。
- 居中卡片，宽度约 640px，输入框在上，结果列表在下。
- 输入 300ms 防抖后自动搜索（多书源并行，沿用现有 `SearchTask`）。
- 结果行：封面缩略 + 书名 + 作者 + 来源标签 + 最新章节。
- 键盘：`↑/↓` 选择、`Enter` 打开详情、`Esc` 关闭；鼠标点击同样打开详情。
- 搜索中的进度、失败的书源、0 结果提示都显示在这个面板内（不再占用主界面）。
- 原来「网络找书源 / 探测新书源」的入口放在 0 结果时出现在面板里。

### ③ 书籍详情

- 左：封面（较大，约 160×220）。
- 右：书名、作者、分类/状态/章节数、简介（默认 3 行，点「展开」看全文）。
- 按钮**只保留一个主按钮**：「开始阅读 / 继续阅读」；「加入书架」改为次级图标按钮。
- 「目录」不再是常驻列表，改为一个按钮 → 从左侧滑出抽屉（当前章高亮 + 章节筛选 + 点击跳转）。
- 顶部只有一个「← 返回」文字按钮，不要一整排按钮。

### ④ 阅读器（沉浸）

```
                      （顶部浮条，鼠标靠近顶部时淡入）
   ← 返回    斗罗大陆 · 第 3 章            目录    Aa
┌──────────────────────────────────────────────┐
│                                              │
│            正文居中列，宽 ≤ 820px             │
│                                              │
│                                              │
├──────────────────────────────────────────────┤
│  ▓▓▓▓▓▓▓░░░░░░  42%   ← 细进度线（常驻，2px） │
│        （底部控制条，鼠标靠近底部时淡入）      │
│      ‹ 上一章     目录      下一章 ›          │
└──────────────────────────────────────────────┘
```

- 顶部/底部浮条**默认隐藏**，鼠标接近窗口顶部/底部 24px 时淡入，静止 2 秒后淡出。
- 正文列宽 700–900（用上 `content_width`，默认 820），左右留白对称。
- 底部常驻一条 2px 细进度线（不占高度、不干扰阅读）。
- 目录抽屉：左侧滑出，遮罩点击关闭，当前章高亮，顶部带章节筛选框。
- 阅读设置：点 `Aa` 弹出浮层（字号 / 字体 / 行距 / 页宽 / 主题 / 首行缩进 / 翻页方式），**即时生效**。
- 保留现有能力：`←/→` 翻章、空格/PageUp/PageDown 翻页、`F5` 忽略缓存重抓、`F11` 全屏、滚动位置恢复。

## 2. 设计 Tokens（严格按方案）

集中放在 `novelfound/ui/theme.py`，**所有 QSS 从这里取值**，不再写散落的内联样式。

```python
# 主界面（暖白，方案指定）
BG_APP      = "#F7F3E9"   # 应用背景（替换 #f4f5f7）
BG_SURFACE  = "#FBF9F3"   # 卡片/浮层（比底色略亮，不用纯白）
BG_HOVER    = "#F1ECE0"   # 悬停态
TEXT_MAIN   = "#333333"   # 正文/标题（方案指定，替换 #1f2328）
TEXT_SUB    = "#8A8578"   # 辅助文字（暖灰）
DIVIDER     = "#E8E2D6"   # 极浅分隔线（尽量少用）
ACCENT      = None        # 强调色待定；先留 token，代码里统一引用
RADIUS      = 8           # 卡片圆角
RADIUS_SM   = 4           # 封面圆角

# 阅读器主题（方案：暖白 / 夜间 / 护眼 #c7edcc）
reader_themes = {
    "warm":  {"name": "暖白", "bg": "#F7F3E9", "fg": "#333333"},   # 新的默认
    "eye":   {"name": "护眼", "bg": "#c7edcc", "fg": "#1d2b1d"},   # 方案指定
    "night": {"name": "夜间", "bg": "#1b1f23", "fg": "#c2c9d1"},   # 方案：深灰底浅灰字
    # 保留 sepia / dark 作为可选，但不作为默认
}
```

要点：

- **去掉所有 `#ffffff` 背景**（封面图除外）。
- **去掉蓝色强调**：按钮主色改用 `TEXT_MAIN` 字重 + 边框区分；等强调色定了只改 `ACCENT` 一个变量。
- **减少边框**：卡片不再用 1px 边框，改用底色差 + 留白；分隔线只在必要处（列表行之间）。
- QSS 没有 `box-shadow`：浮层阴影用 `QGraphicsDropShadowEffect`（`blurRadius≈24`、低透明度），或干脆不用阴影。
- 字体：UI 用系统无衬线；**正文默认给宋体系**（思源宋体 / 宋体，可在设置里改）。

## 3. 组件清单

| 组件                      | 位置                         | 职责                     | 备注                                                 |
| ----------------------- | -------------------------- | ---------------------- | -------------------------------------------------- |
| `Drawer`                | `ui/widgets.py` 新增         | 左侧滑出抽屉 + 半透明遮罩         | 动画：`QPropertyAnimation` 250ms `OutCubic`           |

| `AutoHideBar`           | `ui/widgets.py` 新增         | 顶部/底部自动隐藏条             | 暴露 `show_bars()/hide_bars()/notify_mouse()`，便于测试驱动 |

| `CoverTile`             | `ui/widgets.py` 新增         | 书架网格单元（封面 + 标题 + 进度角标） | 复用 `CoverLabel`                                    |
| `ContinueCard`          | `ui/library_view.py`       | 「继续阅读」大卡               | 显示书名/章节/百分比                                        |
| `SearchPalette`         | `ui/search_palette.py` 新增  | Ctrl+K 搜索浮层            | 复用 `SearchTask`                                    |

| `Toast`                 | `ui/widgets.py` 新增         | 底部轻提示（替代现在的顶部 Banner）  | 6 秒自动消失，不打断操作                                      |

**Banner 的去向**：现有顶部黄色提示条在"安静"设计里太吵。改成两种：

- 需要用户注意的错误 → `Toast`（底部，深色半透明，6 秒消失，可点开 crash.log）；
- 页面内的说明（如"目录获取失败，建议换源"）→ 直接写在页面内容区，不用浮条。

## 6. 分阶段计划

### P0 · 视觉与阅读区（低风险，先看效果）

**改动**

1. `theme.py` 换 tokens（暖白/深灰/去蓝/去边框），`app_stylesheet()` 全面替换。
2. 阅读器正文**居中限宽**：把 `content_width` 接上（`view.setMaximumWidth(...)` + 左右 stretch），保证左右留白对称。
3. 阅读器顶部工具栏 → `AutoHideBar`（默认隐藏，鼠标靠近顶部 24px 淡入）。
4. 底部状态文字 → `ProgressLine`（2px）+ 底部 `AutoHideBar`（上一章/目录/下一章）。
5. `reader_theme` 默认改为 `warm`；`day` 主题的纯白改为暖白。
6. 顶部 `Banner` → `Toast`（底部，自动消失）。

**验收（都要能自动断言）**

- 截图均值颜色接近 `#F7F3E9`（容差 ±6），且不存在整块 `#ffffff` 背景。
- `reader.view.width() <= content_width` 且左右留白差 < 8px。
- 阅读器进入后：顶部/底部浮条 `isVisible() == False`；调用 `show_bars()` 后可见；`hide_bars()` 后隐藏。
- 进度线存在且高度 ≤ 3px。
- 66 单测 + 更新后的界面自检全绿；继续阅读索引 / 滚动恢复 / 封面节流三条回归断言仍在。

**不做**：不动信息架构，左侧栏暂时保留（`Ctrl+B` 仍可收起）。

### P1 · 信息架构（核心改动）

**改动**

1. 新增 `library_view.py` 作为启动页（继续阅读 + 最近阅读 + 书架网格）。
2. 新增 `search_palette.py`，`Ctrl+K` 唤起；**删除左侧常驻结果栏**。
3. `detail_panel.py` → `book_view.py`：精简为封面 + 简介 + 单一主按钮；目录改为抽屉。
4. 左侧栏彻底移除；`QSplitter` 移除。
5. 书源相关入口（导入/订阅/探测/网络找书源）集中到「首选项 → 书源」，0 结果时在搜索面板内给快捷入口。

**验收**

- 启动后 `stack.currentWidget() is library_view`（首屏即书架）。
- `Ctrl+K` 打开搜索面板且输入框获得焦点；`Esc` 关闭。
- 主界面不再存在常驻结果列表（断言旧控件不存在）。
- 详情页只有 1 个 `objectName == "primary"` 的按钮。
- 目录抽屉默认关闭；打开后当前章高亮（沿用现有断言逻辑）。
- 书架网格点击 → 详情 → 「继续阅读」→ 落在上次章节（**这条是回归重点**）。

### P2 · 打磨

**改动**

1. 动画：抽屉 250ms 滑出、浮层 200ms 淡入、控制条 200ms 淡入淡出。
2. 阅读设置浮层（`Aa`）即时生效，替代对话框里的阅读项。
3. 键盘完善：`Ctrl+K` 搜索、`Ctrl+B` 目录、`Esc` 关闭浮层、`←/→` 翻章。
4. 封面网格 hover 效果、书架进度角标。
5. 空状态、加载中骨架（可选）。

**验收**

- 所有动画 `duration()` 落在 200–300ms。
- 控制条：`notify_mouse()` 后可见，静置 2 秒（测试里直接调 `maybe_auto_hide()`）后隐藏。
- 设置浮层改字号后正文立即重绘（断言 `pointSize` 变化）。
- 截图：书架首页、搜索面板、详情、阅读器（暖白/夜间各一张）。

### P0.5 · 左右双页分栏（✅ 已完成，2026-09-10）

用户可在阅读器里随时切换 **单页 / 左右双页**（设置里也有同一项）：

- **只在翻页模式生效**：选「左右双页」会自动切到翻页模式（滚动模式双栏体验差）；
- 双页时每栏宽度 = `(content_width - 64) / 2`，两栏之间留 64px 栏间距，
  整体仍按 `content_width` 居中（实测 820px：左页 378 + 栏距 64 + 右页 378）；
- **分页以段落为单位**：按段落高度切页，不会把一段从中间切断；
  翻一屏 = 左右各前进一页，章末时右页留空（像实体书）；
- **阅读位置改按"段落序号"记录**（新增 `block_index` / `page_index` 字段）：
  跨窗口尺寸、跨单双页切换都能回到原来读到的段落，比像素位置稳得多；
- 窗口尺寸或字号变化后自动重新分页，并停在原段落上（防抖 160ms）。

验收（已通过）：单页 21 页 / 双页 63 页→32 屏；翻屏后左右页首段 0→3、3→5；
状态栏显示"1 / 32 页"；按块索引可定位到对应屏；切回单页后右页隐藏且布局恢复对称。

**第一轮反馈后的修正（同日）：**

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 每栏最后一段被裁掉半截，左右两栏接不上 | 分页时用的可用高度是 `viewport - 4`，**没扣掉文档上下边距（26px×2）**，所以每页实际多塞了约 50px 内容 | 改用文档坐标判断：`blockBoundingRect().bottom() > viewport - documentMargin` 就换页——放不下的段落**整体留到下一页** |
| 鼠标在正文上滚轮会滚动单栏而不是翻页 | `QTextBrowser` 先吃掉了 wheel 事件 | 在事件过滤器里拦截两栏的 `QEvent.Wheel`：翻页模式下统一翻屏（只有"某段比整页还高"时才让该页自己滚） |
| 双页时每栏太窄 | 原来是"总宽 = content_width，两栏平分" | 改为**每栏按单页宽度**取：`col = min(content_width, (可用宽 - 栏距) / 2)`，宽屏上两栏都是完整阅读宽度，窗口不够宽才等比缩小 |
| 不知道当前是第几章 | 章节标题只在自动隐藏的顶部浮条里 | 正文上方新增**常驻章节标题**（小字、居中、超长自动省略），切章/加载中立刻更新 |

新增断言：左右页内容均未被裁切、每栏宽度合理、滚轮在正文上翻页、章节标题常驻显示。

**第二轮反馈后的修正（同日）：**

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 每章只有第一页装满，后续每页只剩一段 | 分页判断用了**文档绝对坐标**，第一页之后每段都被判成"放不下" | 改成与"本页首段顶部"比较：`rect.bottom() - page_top > viewport - 2*margin` |
| 鼠标移到窗口顶部唤不出顶部浮条 | 顶部被章节标题栏占住，MouseMove 落在它/画布上，而过滤器只装在正文 viewport | 给 canvas / page / chapter_header 也开鼠标跟踪并装事件过滤器 |
| 想知道当前章节 | —— | 每章正文开头加**大字号居中标题**（正文字号+4、加粗），仅第一页显示 |

新增断言：每页包含多个段落、后续页也装满、章首标题字号大于正文且居中、鼠标移到标题栏能唤出浮条。

**第三轮反馈后的修正（同日，改成"按行分页"）：**

段落分页的根本缺陷：段落整段不切断 → 长段落要么撑破页面（冒出页内滚动条），
要么一段独占一页。这一轮把分页粒度从**段落**改成**行**：

| 项 | 改法 |
| --- | --- |
| 分页锚点 | 从"段落序号"改为**字符偏移** `char_offset`（`_page_offsets` 记录每页起始字符），跨字号、跨单双页、跨窗口尺寸都稳定 |
| 页内容 | 一页 = 一个字符区间 → 切成若干"段落片段" `(段落号, 起, 止)`；被切断的段落在下一页续排，**续排片段不带首行缩进** |
| 超长段落 | 拆到多页，不再需要页内滚动条（`ScrollBarAsNeeded` 只作兜底） |
| 高度计算 | `QTextLine.height()` 在比例行距下只是**文字高度**，真实行步进要乘行距倍数（30 × 1.9 = 57）——之前漏乘导致每页多塞 2~3 行、底部被裁（见 `TROUBLESHOOTING.md` 11.7） |

验收（已通过）：33 页 **0 溢出**；页面填充率最低 0.917、平均 0.963；
超长段落（200 次重复）被正确拆到 19 页；`char_offset` 记录后重新定位误差 0。
新增断言："所有页均不溢出（行级分页）"、"每页都装满（不是只塞一行）"。
