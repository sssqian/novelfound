# UI设计方案：现代沉浸式小说阅读器

请将整个应用设计为一款现代化 PC 端小说阅读器，相当于附带了一个搜索功能。

设计参考：

- Kindle 的沉浸式阅读体验
- Notion 的简洁信息组织
- macOS 应用的精致和克制

整体设计关键词：

> 安静、沉浸、专注、现代、无干扰

不要设计成传统网站式布局，而应该更像一个专业阅读软件。

---

# 一、整体视觉风格

采用：

- Minimalism（极简主义）
- Content First（内容优先）
- Soft UI（柔和界面）

设计原则：

1. 阅读内容永远是视觉中心
2. UI 控件应该隐藏，而不是主动占据空间
3. 避免大量边框、按钮、颜色装饰
4. 保持宽松留白，让用户长时间阅读不会疲劳

整体感觉：

类似：

- Kindle PC版
- Apple Books
- Notion 阅读页面

而不是：

- 新闻网站
- 小说广告网站
- 传统后台管理系统

---

# 二、颜色设计

默认采用护眼阅读主题：

背景：

- 米白色 / 暖白色
- 避免纯白 (#FFFFFF)

推荐：

background:
#F7F3E9

正文：

深灰色

避免纯黑：

#333333

辅助文字：

浅灰色

---

同时预留主题切换：

1. 白天模式
   
   - 暖白背景
   - 深灰文字

2. 夜间模式
   
   - 深灰背景
   - 浅灰文字

3. 护眼模式
   
   - #c7edcc

---

# 三、页面布局

主阅读页面应该最大化阅读区域。

整体结构：

+--------------------------------+
|                                        |
|                                        |
|          小说标题               |
|                                        |
|      正文阅读区域           |
|                                        |
|                                        |
|                                        |
+--------------------------------+

默认状态：

隐藏所有非必要 UI。

---

# 四、阅读区域设计

核心区域：

最大宽度限制：

约 700-900px

原因：

避免一行文字过长导致阅读困难。

正文：

字体：

- 18px~22px

行高：

1.8~2.2

段落：

增加间距。

不要使用密集文本。

例如：

错误：

文字文字文字文字文字文字文字文字文字

文字文字文字文字文字文字文字文字文字

正确：

文字文字文字文字文字文字文字。

文字文字文字文字文字文字文字。

---

# 五、目录设计

章节目录不要永久显示。

采用：

隐藏式侧边栏。

默认：

用户只看到正文。

用户点击：

目录按钮

↓

左侧滑出章节列表。

目录：

- 当前章节高亮
- 支持搜索章节
- 支持快速跳转

---

# 六、控制栏设计

控制栏不要固定占据空间。

采用：

鼠标移动到页面底部时显示。

包含：

- 上一章
- 下一章
- 目录
- 设置
- 阅读进度

平时隐藏。

---

# 七、阅读设置面板

提供：

字体调整：

- 字体大小
- 字体类型

页面：

- 行间距
- 页面宽度

主题：

- 白天
- 夜间
- 护眼

设计为简洁浮层。

类似 macOS 设置面板。

---

# 八、动画和交互

动画原则：

自然、缓慢、克制。

不要使用：

- 炫酷动画
- 大量弹窗
- 复杂过渡

应该有：

- 目录滑出动画
- 设置面板淡入
- 页面切换过渡

动画时间：

200ms~300ms

---

# 九、避免事项

不要：

❌ 大量按钮

❌ 蓝色默认网页风

❌ 卡片堆叠

❌ 广告式布局

❌ 复杂导航栏

❌ 信息密度过高

目标：

让用户打开软件后，可以马上开始阅读。

---

最终效果目标：

用户打开软件后的第一感受：

“这是一个安静的电子书阅读空间。”

而不是：

“这是一个网页应用。”
